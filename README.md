# Lego III: Inferência Causal

Minhas anotações das aulas de Lego III (IESP-UERJ, 2026.1), disciplina de inferência causal com Pedro H. G. Ferreira de Souza, Carlos Antonio Costa Ribeiro e Rogério J. Barbosa.

**Site:** [felipelamarca.com/Lego-III](https://felipelamarca.com/Lego-III/)

| Pasta | Conteúdo |
|:--|:--|
| `aulas/` | uma página por aula (`aula-NN.qmd`); `_aula-NN.qmd` são rascunhos |
| `trabalhos/` | listas entregues, com enunciado, código e dados |
| `references.bib` | bibliografia da disciplina |
| `_freeze/` | resultados já computados, usados pelo CI |
| `_extensions/` | o template [Course Notes](https://github.com/felipelmc/Course-Notes-Template) |

Para renderizar localmente: instale os pacotes do `DESCRIPTION` e rode `quarto render`. Depois de mudar uma página com código R, faça o commit de `_freeze/` junto, porque o GitHub Actions publica sem executar R.

As anotações são pessoais e podem conter erros. Citações literais seguem o original, e trechos escritos com auxílio de IA aparecem em caixas identificadas.
